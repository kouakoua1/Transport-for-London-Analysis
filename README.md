# Transport for London (TfL) Data Analysis Project

## Introduction

This project presents a detailed analysis of open data provided by Transport for London (TfL). London's transport network is one of the busiest and most complex in the world. Understanding travel patterns, service performance, and user behaviour is crucial for effective planning, operational management, and policy-making. This analysis aims to uncover key trends and provide data-driven insights to support strategic decision-making related to the capital's transport infrastructure. 

## Objectives

The primary objectives of this analysis are:

* Uncover patterns and trends in station usage across London 
* Identify operational hotspots and capacity stress points 
* Evaluate the distribution of passenger traffic across the network 
* Support strategic decision-making for future operational and infrastructure planning 

## Tools Used

* **Python**: Employed for data acquisition, cleaning, transformation, exploratory data analysis, advanced analysis and generating core visualisations.
* **Power BI and Tableau**: Used for creating interactive dashboards and visualising key metrics for presentation and exploration.

The analysis followed these key steps:
1. **Business & Data Understanding** 
2. **Data Preparation and Quality Control** 
3. **Exploratory Data Analysis (EDA)**

## Key Metrics Tracked

* Total annualised traffic per station 
* Busiest stations 
* Entry vs. exit balance 
* Average daily entries/exits 
* Traffic variability (standard deviation)
